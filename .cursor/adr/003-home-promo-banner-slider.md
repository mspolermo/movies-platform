# 003. Рекламный слайдер на Home (статика, без перехода)

- **Статус:** Accepted
- **Дата:** 2026-07-25
- **Участники:** —

## Контекст

На главной нужен промо-блок: баннеры на всю ширину контентной колонки (`--max-layout-width`, не break-out из `.main`), infinite-loop, точки пагинации поверх слайда, autoplay, свайп на touch. Перехода на карточку фильма и CMS/API нет.

В проекте уже есть `shared/ui/HorizontalCarousel` (scroll + стрелки для `FilmsCarousel` и т.п.). Расширять его loop/autoplay/кастомными dots ради **одного** места на Home — раздует shared-примитив без выгоды для остальных потребителей.

Контент сейчас — локальные креативы в репозитории. Каталог жанровых каруселей ниже по странице — отдельный UX.

## Решение

| Инвариант | Деталь |
|-----------|--------|
| Слой FSD | Виджет `widgets/PromoBannerSlider` (композиция главной); `pages/HomePage` только вставляет виджет |
| Контент (сейчас) | Статика в слайсе: `assets/` (WebP) + `model/banners.ts` (`PROMO_BANNERS`); **не** `shared/assets`, не чужой CDN |
| Контент (будущее) | При появлении админки управление креативами/ротацией можно вынести туда (API + CMS); это **отдельный ADR** + контракты, не расширение текущего инварианта «втихаря» |
| Shared-карусель | `HorizontalCarousel` остаётся scroll/arrows; **без** loop / autoplay / promo-dots |
| Реализация промо | Свой track + loop-scroll (`useLoopingSlideScroll`), autoplay (`useCarouselAutoplay`), overlay-pagination в виджете |
| Клик | Нет `Link` / навигации по баннеру |
| UX | Loop после mount (SSR без клонов — первый кадр = banner0); точки внутри слайда (палитра `colors.scss`); autoplay с паузой hover/touch/focus и на скрытой вкладке, reset таймера после user nav; выкл. при `prefers-reduced-motion` (snap остаётся); **без стрелок**; листать — свайп/drag по треку + точки |
| Заголовок Home | Визуально без `h1` «MovieLand»; для a11y — `Page titleVisuallyHidden` |
| API/CMS | Пока нет бэкенд-контракта; смена баннеров = правка ассетов/модели + деплой клиента |

Запрещено без нового ADR:

- Клик по баннеру → `/films/:id` или внешний URL «как в OLD»
- Баннеры с чужих CDN
- Перенос loop/autoplay/promo-pagination в `HorizontalCarousel` «на всякий случай»
- Entity/feature + API баннеров без задачи на админку/CMS

Клиент: `apps/client/src/widgets/PromoBannerSlider`.  
Врезка: `pages/HomePage` — первый блок контента страницы.

## Последствия

**Плюсы**

- Паритет UX главной без долга OLD (клик, чужие картинки)
- Shared UI карусели фильмов не раздувается под одноразовый promo-кейс
- Нет RPC/схемы БД под рекламу на текущем этапе
- Ассеты рядом со слайсом — понятный FSD-граничный контент

**Минусы / риски**

- Смена креативов = деплой клиента (пока нет админки)
- Отдельная scroll/loop-логика в виджете (осознанный trade-off vs раздувание shared)
- Без CMS нельзя таргетировать / крутить по расписанию из UI

**Поддержка**

- Новые баннеры — WebP в `widgets/PromoBannerSlider/assets` + запись в `PROMO_BANNERS`
- Цвета только из `apps/client/src/app/styles/colors.scss`
- Не возвращать кликабельные баннеры и не тащить promo-фичи в `HorizontalCarousel` без ADR
- Gap миграции OLD promo закрыт при своих ассетах (см. `.cursor/temp/backlog.md` F12)

## Альтернативы

1. **Порт OLD 1:1** (клик → film, DOM-хаки карусели) — отвергнуто: не актуальный бренд/контент, ложная навигация.
2. **Расширить `HorizontalCarousel`** (loop + autoplay + dots в shared) — отвергнуто: нужно в одном месте; кастомная пагинация/autoplay сильно усложняют UI-kit для всех каруселей фильмов.
3. **Feature-слой вместо widget** — отвергнуто: нет user scenario (даже клика нет); это блок композиции страницы → widget.
4. **CMS / API баннеров (админка)** — отложено: появится админка/продуктовая задача на ротацию → новый ADR + контракты; до тех пор статика в папке виджета.
